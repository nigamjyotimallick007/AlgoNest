Lesson 3: Understanding HTML Heading Elements

What is a Heading in HTML?

A heading in HTML is like a title for a section of text. It helps organize content by giving important topics a clear, bold title. Think of headings as chapter names in a book—each chapter has a title that tells you what it's about.

Why Use Headings?

• Better Reading: They make text clear and easy to follow.
• Google-Friendly: Search engines like headings (they help in ranking websites).
• Help for Everyone: Screen readers use headings to help visually impaired users.

Types of Headings in HTML

HTML headings come in six levels. Each level has a different size and importance.

🔹 1. <h1> - Main Title (Most Important)

• This is the biggest heading.
• Used for the main topic or title of a webpage.
• Every webpage should only have one <h1> (Think of it like the name of a book).

Example: 

                            
                        <h1>Welcome</h1>

🔹 2. <h2> - Section Title (Less Important Than <h1>)

• This is a subheading used to divide sections.
• It's smaller than <h1>, but still important.
• Think of it like chapter titles in a book.

Example: 

                            
                        <h2>About Us</h2>

🔹 3. <h3> - Subsection Title

• This is a smaller subheading inside a <h2> section.
• Use it for topics inside a section.

Example: 

                            
                        <h3>Information</h3>

🔹 4. <h4> - Detailed Heading

• Even smaller than <h3>.
• Use it when you need more details inside a topic.

Example: 

                            
                        <h4>A Coffee with the PC</h4>

🔹 5. <h5> - Tiny Heading

• This is a less important heading inside <h4>.
• Rarely used, but sometimes helpful for detailed organization.

Example: 

                            
                        <h5>A Founder's Story</h5>

🔹 6. <h5> - Smallest Heading

• Least important, smallest in size.
• Usually used for very small sections.

Example: 

                            
                        <h6>The Early Days</h6>

📝 Best Practices for Using Headings
✓ Use <h1> once (for the main title).
✓ Follow order (<h1> → <h2> → <h3>, etc.).
✓ Headings should describe the content (not just be for style).
✓ Use headings to organize information, not just make text bigger.
💡 Think of headings like a tree:
• <h1> is the root (main title).
• <h2> are the big branches (sections).
• <h3> and smaller ones are the leaves (detailed parts).

In simple words:
Headings are like chapter titles in a book—each one helps people understand the content step by step. They are of 6 types from h1 to h6, higher the number next to h is smaller the size.
